# nexo - 83
Projeto acadêmico de desenvolvimento Web utilizando HTML.

A nexo 83 é uma agência de desenvolvimento web. O site foi criado para apresentar a empresa, seus serviços, produdos e canais de atendimento

Páginas do site

Home: apresentação da empresa e principais serviços oferecidos.

Quem somos: missao, diferenciais e equipe.

Produtos: catálogo de soluções digitais

Serviços: apresentação dos serviços e etapas de desenvolvimento.

Contato: informaçoes e canais demonstrativos de atendimento.
